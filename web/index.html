How it works

01

Rules, first

A hand-built engine maps Arabizi to Arabic letters, following the regional conventions (9 is qaf in Morocco, sad in Egypt), and returns a ranked list of readings instead of one guess.

02

A learned layer

Trained on hundreds of real social-media sentences, a small local model - dialect classifier, word table, character language model - reranks candidates toward natural Arabic. No GPU, no API, no setup.

03

Optional LLM picker

For the truly ambiguous cases, the top candidates go to an LLM (Groq free tier by default) that picks the intended reading. The LLM chooses; it never guesses from scratch.
